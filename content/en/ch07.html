Many feedback systems are a linear plant in a loop with one memoryless nonlinearity: a saturating actuator, a relay, a dead zone. This chapter uses frequency-domain tools, familiar from linear control, to analyze them.

\[ \dot x = Ax + Bu, \quad y = Cx + Du, \quad u = -\psi(t, y) \]

7.1 Absolute stability

Often we do not know \(\psi\) exactly, only that it lies in a sector \([\alpha, \beta]\). The loop is absolutely stable if the origin is globally uniformly asymptotically stable for every nonlinearity in the sector. (Aizerman's conjecture, that it is enough to check the linear gains \(\alpha \le k \le \beta\), is false.)

The circle criterion

Circle criterion (scalar, \(G\) Hurwitz)

Let \(D(\alpha, \beta)\) be the closed disk whose diameter is the segment \([-1/\alpha, -1/\beta]\) of the real axis. The loop is absolutely stable if

  • \(0 < \alpha < \beta\): the Nyquist plot of \(G(j\omega)\) stays outside \(D(\alpha, \beta)\) and does not encircle it;
  • \(0 = \alpha < \beta\): the Nyquist plot stays to the right of the vertical line \(\operatorname{Re} s = -1/\beta\);
  • \(\alpha < 0 < \beta\): the Nyquist plot stays inside \(D(\alpha, \beta)\).

It looks like a Nyquist criterion where the critical point \(-1/k\) is smeared into a disk covering every gain \(k \in [\alpha, \beta]\), and it is proved with a Lyapunov function \(x^\top P x\) built from the Kalman–Yakubovich–Popov lemma (Chapter 6).

Try this

  • With \(\alpha = 0\), find the largest \(\beta\) for which the plot stays right of the line: that is the largest sector \([0, \beta]\) this test certifies.
  • Raise \(\alpha\) above 0. The forbidden region shrinks from a half-plane to a disk, so a larger \(\beta\) becomes possible.

The Popov criterion

If \(\psi\) is time-invariant, more can be proved. The Popov criterion asks for a \(\gamma \ge 0\) such that

\[ \frac{1}{k} + \operatorname{Re}\big[(1 + j\omega\gamma)\, G(j\omega)\big] > 0 \quad \text{for all } \omega \]

for a sector \([0, k]\). Graphically: plot \(\operatorname{Re}G(j\omega)\) against \(\omega\operatorname{Im}G(j\omega)\) (the Popov plot); the loop is absolutely stable if a straight line through \(-1/k\) with slope \(1/\gamma\) leaves the whole plot to its right. The Lyapunov function behind it is of the Lur'e type, \(x^\top P x + 2\gamma\int_0^y \psi(\sigma)\,d\sigma\).

7.2 The describing function method

To predict a limit cycle, assume the oscillation is nearly sinusoidal, \(y \approx a\sin\omega t\). The nonlinearity's output is periodic; keep only its first harmonic. The ratio of that harmonic to the input is the describing function \(\Psi(a)\), an amplitude-dependent gain. Harmonic balance around the loop then requires

\[ 1 + \Psi(a)\, G(j\omega) = 0 \quad\Longleftrightarrow\quad G(j\omega) = -\frac{1}{\Psi(a)} \]

Each intersection of the Nyquist plot with the locus \(-1/\Psi(a)\) predicts a limit cycle with amplitude \(a\) and frequency \(\omega\).

NonlinearityDescribing function \(\Psi(a)\)
relay, \(\pm M\)\(4M/(\pi a)\)
cubic, \(y^3\)\(3a^2/4\)
saturation (slope 1, limit \(\delta\)), \(a > \delta\)\(\frac{2}{\pi}\Big[\sin^{-1}\frac{\delta}{a} + \frac{\delta}{a}\sqrt{1 - \frac{\delta^2}{a^2}}\Big]\)
An approximation, not a proof

The describing function works when \(G\) is a good low-pass filter, so that the higher harmonics are small. For large \(\varepsilon\) the Van der Pol wave becomes far from sinusoidal and the prediction degrades. The book also gives conditions under which the prediction can be made rigorous, with error bounds.

Key takeaways

For a linear plant with a sector-bounded nonlinearity, the circle and Popov criteria give absolute stability from the Nyquist plot. The describing function replaces a nonlinearity by an amplitude-dependent gain and predicts limit cycles by harmonic balance; it is approximate, and best when the linear part filters out harmonics.
