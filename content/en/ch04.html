Lyapunov's idea: to know whether a system returns to equilibrium, you do not need to solve its equations. Find a function that behaves like energy, a bowl with its bottom at the equilibrium, and check that it never increases along trajectories.

4.1 Stability of an equilibrium

Let \(x = 0\) be an equilibrium of \(\dot x = f(x)\). It is

  • stable if for every \(\varepsilon > 0\) there is \(\delta > 0\) such that \(\|x(0)\| < \delta\) implies \(\|x(t)\| < \varepsilon\) for all \(t \ge 0\): start close, stay close;
  • unstable if it is not stable;
  • asymptotically stable if it is stable and \(\delta\) can be chosen so that \(x(t) \to 0\) as \(t \to \infty\).

Sign definiteness

A function \(V\) with \(V(0) = 0\) is positive definite if \(V(x) > 0\) for \(x \ne 0\) and positive semidefinite if \(V(x) \ge 0\). For a quadratic form \(V = x^\top P x\) with \(P\) symmetric, this is decided by the eigenvalues of \(P\), or equivalently by Sylvester's test on its leading principal minors.

Lyapunov's theorem

Theorem 4.1 (Lyapunov's direct method)

Let \(V: D \to \mathbb{R}\) be continuously differentiable and positive definite on a domain \(D\) containing the origin. Along trajectories,

\[ \dot V(x) = \frac{\partial V}{\partial x} f(x) \]

If \(\dot V(x) \le 0\) in \(D\), the origin is stable. If \(\dot V(x) < 0\) in \(D \setminus \{0\}\), it is asymptotically stable.

\(\dot V\) is computed from \(f\) directly, without solving anything. The level sets \(V(x) = c\) are closed curves around the origin; \(\dot V \le 0\) means trajectories can cross them only inward.

Example 4.2: a first-order system

For \(\dot x = -g(x)\) with \(x\,g(x) > 0\) for \(x \ne 0\), take the area under \(g\) as \(V\). Then \(\dot V = -g(x)^2 < 0\).

Example 4.3: the frictionless pendulum

The natural candidate is the energy, \(V = a(1 - \cos x_1) + \tfrac12 x_2^2\). Its derivative is exactly zero, so the theorem gives stability, and that is all that is true: the pendulum swings forever on a level curve of \(V\).

Example 4.4: the pendulum with friction

With friction, the energy gives \(\dot V = -b x_2^2\), which is zero on the whole \(x_1\)-axis. It is only negative semidefinite, so Theorem 4.1 again gives only stability, although the pendulum clearly comes to rest. Khalil then builds a better \(V\): energy plus a quadratic form with a cross term, with coefficients chosen to cancel the indefinite terms in \(\dot V\).

Lesson

The conditions of Lyapunov's theorem are only sufficient. Failing to prove asymptotic stability with one \(V\) says nothing about the system; it may only mean the wrong \(V\) was chosen.

The variable gradient method

Instead of guessing \(V\), guess its gradient \(g(x) = \nabla V\) with unknown coefficients. Choose them so that \(\dot V = g^\top f\) is negative definite and so that the Jacobian of \(g\) is symmetric (the condition for \(g\) to be a gradient). Then integrate to get \(V\).

Global asymptotic stability

Theorem 4.2 (Barbashin–Krasovskii)

If \(V\) is positive definite on all of \(\mathbb{R}^n\), radially unbounded (\(V(x) \to \infty\) as \(\|x\| \to \infty\)), and \(\dot V < 0\) for all \(x \ne 0\), then the origin is globally asymptotically stable.

Why is radial unboundedness needed? Without it the level sets need not be closed, and a trajectory can run off to infinity while \(V\) keeps decreasing.

Instability: Chetaev's theorem

Theorem 4.3 (Chetaev)

Suppose \(V(0) = 0\) and there are points arbitrarily close to the origin with \(V > 0\). Let \(U = \{x \in B_r : V(x) > 0\}\). If \(\dot V > 0\) in \(U\), the origin is unstable.

4.2 The invariance principle

Example 4.4 shows the frustration of a semidefinite \(\dot V\). LaSalle's principle removes it: trajectories converge to the largest invariant set inside \(E = \{x : \dot V(x) = 0\}\).

LaSalle's theorem and Corollary 4.1

Let \(\Omega\) be a compact set that is positively invariant, and \(\dot V \le 0\) in \(\Omega\). Then every solution starting in \(\Omega\) approaches the largest invariant set \(M\) in \(E = \{x \in \Omega : \dot V = 0\}\). If the only solution that can stay identically in \(E\) is \(x(t) \equiv 0\), the origin is asymptotically stable.

4.3 Linear systems and linearization

For \(\dot x = Ax\), the origin is asymptotically stable exactly when \(A\) is Hurwitz (all eigenvalues have negative real part). Equivalently, for any \(Q = Q^\top > 0\) the Lyapunov equation

\[ P A + A^\top P = -Q \]

has a unique solution \(P = P^\top > 0\), and \(V = x^\top P x\) is a Lyapunov function. For a nonlinear system with Jacobian \(A\) at the origin, Theorem 4.7 (Lyapunov's indirect method) says: if \(A\) is Hurwitz the origin is asymptotically stable; if \(A\) has an eigenvalue with positive real part it is unstable; otherwise linearization decides nothing. The same \(x^\top P x\) then serves as a local Lyapunov function for the nonlinear system, which is how the region-of-attraction estimates of Chapter 8 start.

4.4–4.9 The rest of the chapter

  • Comparison functions (class \(\mathcal K\), \(\mathcal K_\infty\), \(\mathcal{KL}\)) give a compact way to state all definitions: the origin is uniformly asymptotically stable if \(\|x(t)\| \le \beta(\|x(t_0)\|, t - t_0)\) with \(\beta \in \mathcal{KL}\).
  • Nonautonomous systems \(\dot x = f(t, x)\) need uniformity in \(t_0\) and a \(V(t, x)\) bounded above and below by class \(\mathcal K\) functions.
  • Exponential stability follows when \(k_1\|x\|^a \le V \le k_2\|x\|^a\) and \(\dot V \le -k_3\|x\|^a\).
  • Converse theorems say that if the origin is (exponentially) stable, a Lyapunov function exists. So searching for one is never hopeless in principle.
  • Boundedness and ultimate boundedness: when \(\dot V < 0\) only outside a ball, solutions eventually enter a set and stay there (Chapter 9 uses this).
  • Input-to-state stability (ISS): \(\|x(t)\| \le \beta(\|x(0)\|, t) + \gamma(\sup\|u\|)\). Bounded inputs give bounded states, and the effect of the initial state dies out.

Application: a balancing robot

A legged robot standing upright behaves like an inverted pendulum, an equilibrium at the top of a hill. A controller \(u = -2\sin x_1 - b x_2\) turns the hill into a bowl: the closed loop is exactly the pendulum with friction from Example 4.4. The controller keeps the robot upright; the Lyapunov function proves that it does.

Key takeaways

A positive definite \(V\) with \(\dot V \le 0\) proves stability; \(\dot V < 0\) proves asymptotic stability; radial unboundedness makes it global. The conditions are sufficient, not necessary, so the art is in choosing \(V\). LaSalle's principle rescues semidefinite \(\dot V\), Chetaev's theorem proves instability, and for linearizations the Lyapunov equation constructs \(V\) automatically.
