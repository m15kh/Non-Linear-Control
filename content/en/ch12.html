The first half of the book analyzes systems; the second half designs controllers. The simplest approach is the one used throughout engineering: linearize, design a linear controller, and use the analysis tools to find out where it works.

12.1 Control problems

  • Stabilization: find \(u = \gamma(x)\) (state feedback) or a dynamic output feedback that makes a desired equilibrium asymptotically stable.
  • Tracking and regulation: make an output follow a reference \(r(t)\) despite disturbances \(w(t)\).
  • Local, regional, semiglobal, global: results differ in how large the guaranteed region of attraction is. Local means "some neighborhood"; regional means a given set; semiglobal means any given compact set, by tuning the design; global means everywhere.

12.2 Stabilization via linearization

Linearize \(\dot x = f(x, u)\) at the equilibrium \((0, 0)\):

\[ A = \frac{\partial f}{\partial x}(0, 0), \qquad B = \frac{\partial f}{\partial u}(0, 0) \]

If \((A, B)\) is stabilizable, choose \(K\) so that \(A - BK\) is Hurwitz (pole placement, LQR, …) and apply \(u = -Kx\) to the nonlinear system. By Lyapunov's indirect method (Theorem 4.7) the origin of the closed loop is exponentially stable. The Lyapunov function \(x^\top P x\) of the linear closed loop then gives an estimate of the region of attraction, as in Chapter 8.

Try this

  • Set \(k_1 < 1\): the closed-loop linearization has a positive eigenvalue and the pendulum falls.
  • With \(k_1 = 3\) and a generous \(u_{\max}\), even large angles are caught. Lower \(u_{\max}\) below 1: no admissible torque can beat gravity near \(90^\circ\), and the region of attraction shrinks to a neighborhood of the origin.

12.3 Integral control

A controller designed for a model only drives the error to zero if the model is exact. Constant disturbances and parameter errors leave a steady-state error. The classic cure is to integrate the error,

\[ \dot\sigma = y - r, \qquad u = -K_1 x - K_2 \sigma \]

and stabilize the augmented system \((x, \sigma)\). At any equilibrium of the closed loop \(\dot\sigma = 0\), so \(y = r\) exactly. The integrator state settles at whatever value cancels the unknown constant disturbance. The disturbance does not need to be measured or known; it only has to be constant (or slowly varying), and the closed-loop equilibrium has to remain stable.

12.4 Integral control via linearization

For a nonlinear plant, the equilibrium \((x_{ss}, u_{ss})\) that gives \(y = r\) depends on \(r\) and on the unknown disturbance. Linearizing at that equilibrium and designing \(K_1, K_2\) for the augmented linearization gives a controller whose implementation does not require knowing \((x_{ss}, u_{ss})\): the integrator finds them. Local exponential stability follows from Theorem 4.7, robustly with respect to small parameter errors.

12.5 Gain scheduling

A linear design is valid only near one operating point. Gain scheduling designs a family of linear controllers, one for each operating point parameterized by a scheduling variable \(\alpha\) (speed, altitude, set point…), and interpolates the gains as \(\alpha\) changes. It is the standard method in flight control. The analysis of Section 9.6 explains when it works: the scheduling variable must change slowly compared with the closed-loop dynamics.

Key takeaways

A linear controller designed on the linearization stabilizes the nonlinear system locally. How large "locally" is depends on the nonlinearity and on actuator limits, and Lyapunov estimates quantify it. Integral action removes steady-state error from constant disturbances without measuring them. Gain scheduling stretches linear designs over a range of operating points that change slowly.
